# Features

DataVista JS is a browser-based workspace for exploring CSV and JSON data without a backend.

## Dataset import

Users can import CSV and JSON files from their device. The app parses the file, previews the first rows, and saves the dataset locally after the user confirms the dataset name and description.

## Table explorer

The dataset table supports row search, column sorting, and limited row rendering for better performance on larger files.

## Insights

The insights page summarizes rows, columns, duplicate rows, missing values, and numeric column statistics such as average, minimum, maximum, and sum.

## Chart builder

The chart builder can create bar, line, and pie charts from imported data by selecting a label column and numeric value column.

## Backup

Users can export the workspace as JSON and import a previous backup later.

## Offline support

The project includes a web app manifest and a service worker so the app can work offline after the first load.
