# Deployment

DataVista JS is a static frontend project and can be deployed on any static hosting platform.

## GitHub Pages

1. Push the project files to a GitHub repository.
2. Open the repository settings.
3. Go to Pages.
4. Choose Deploy from a branch.
5. Select the main branch and root folder.
6. Save the settings.

The app should be available at:

```text
https://yaduvanshi742.github.io/datavista-js/
```

## Other platforms

The project can also be deployed on Netlify, Vercel, Cloudflare Pages, or Firebase Hosting.

No build step is required.
